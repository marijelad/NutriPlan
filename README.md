 NutriPlan - Meal Planner & Nutrition Dashboard

Built with HTML, CSS and vanilla JavaScript.

 Features
- 30+ connected HTML pages
- Responsive navigation and layout
- Meal-plan generator with localStorage
- Recipe search and category filters
- Favorites stored locally
- Interactive shopping list
- Macro calculator
- Custom Canvas charts (no external JS libraries)
- FAQ accordion, contact demo, settings and dark mode
- Local SVG artwork for all major visuals

 Important
This is a fictional portfolio demo and does not provide medical advice or real payment/authentication services.
